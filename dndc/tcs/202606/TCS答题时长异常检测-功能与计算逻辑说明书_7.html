1概述

业务问题。积分答题环节中,部分用户存在乱答、过快敷衍答题以补领积分的行为,需要从答题时长维度进行甄别,作为发放积分的人工审核依据。同时,部分单题答题时间因用户中途离开等中断行为而异常偏长,直接计入会污染问卷整体时长统计,需要在题目维度先做清洗,再在问卷维度判断整卷是否异常。

两步流程。整套逻辑分两步:

  1. 第一步 · 题目维度(清洗): 在车系粒度下统计单题答题时间的 $\mu$、$\sigma$,识别超过分位门槛(如 95%)的超时单题,以 $\tfrac{1}{3}\mu_题$ 替代后,逐份问卷求和得到推定答题时长 $y$。
  2. 第二步 · 问卷维度(判定): 在车系粒度下统计 $y$ 的 $\mu_卷$、$\sigma_卷$,对每份问卷算 $Z_卷$、$P_卷$;$P_卷$ 低于阈值(如 5%)的问卷判为异常·过快/乱答,在人工审核表单高亮。

统计粒度。全部统计以车系为单位;车系样本量不足时,以品牌兜底。本文档中所有"全品牌 / 全车系"指的就是这两个聚合层级。

3业务计算流程

3.1埋点设计与单题答题时间计算

所有上游统计都依赖一份干净的"单题作答时间"数据 $\{x_1, x_2, \ldots\}$。它由前端两类埋点采集 + 后端简单加减得到。

采集的埋点事件(共 2 类):

#事件触发时机记录字段
1start_click用户点击「开始回答」按钮user_id, questionnaire_id, click_time
2answer_update用户某次提交或修改某道题user_id, questionnaire_id, question_id, update_time

单题答题时间计算公式。设某用户某次会话的事件序列(按时间升序):

$$E_0 = \text{start\_click}\;(t_0),\quad E_1, E_2, \ldots, E_n = \text{answer\_update}\;(t_1,\ldots,t_n)$$

记第 $i$ 个 answer_update 事件作答的题目编号为 $q_i$。事件间隔(归属给该次更新的那道题):

$$\Delta_i \;=\; t_i - t_{i-1}\qquad (i = 1, 2, \ldots, n)$$

某道题 $Q$ 的总答题时间 = 所有归属于它的间隔之和(自然支持多次修改累加):

$$x_Q \;=\; \sum_{\substack{1 \le i \le n \\ q_i = Q}} \Delta_i$$

示例:用户打开问卷,顺序答 Q1、Q2,后回去改 Q1,再答 Q3。

事件时间$q_i$$\Delta_i$归属
start_click0 s———
answer_update10 sQ110 sQ1
answer_update25 sQ215 sQ2
answer_update40 sQ1(回去修改)15 sQ1
answer_update60 sQ320 sQ3

累加后:$x_{Q_1} = 10 + 15 = 25$ 秒,$x_{Q_2} = 15$ 秒,$x_{Q_3} = 20$ 秒。

两个边界情况 首题没有"上一题":第一个 answer_update 的间隔以 start_click 时间为锚点($t_0$ = click_time),自然处理,无需特判。
用户中途离开/接电话:产生的极长间隔会被吸收到"当时正在被修改"那道题的 $x_Q$ 中。这类异常值在下一节 §3.2-④/⑤ 的"超时题替代"环节统一处理(P题 ≥ 95% 时用 $\tfrac{1}{3}\mu_题$ 替代),采集层不做特殊处理。

3.2第一步 · 题目维度 · 推定答题时长

①

收集单题作答时间。针对车系下所有问卷,通过埋点获得每一道单题的实际作答时间集合:

$$\{x_1, x_2, x_3, \ldots, x_{n_题}\}$$
②

计算单题平均时长 $\mu_题$。

$$\mu_题 = \frac{1}{n_题}\sum_{i=1}^{n_题} x_i$$
③

计算单题标准差 $\sigma_题$(总体标准差,除以 $n_题$)。

$$\sigma_题 = \sqrt{\,\frac{1}{n_题}\sum_{i=1}^{n_题}(x_i - \mu_题)^2\,}$$
④

计算单题保留上限(纳入门槛时间)。取 $P_{题门槛} = 95.0\%$(可配,1 位小数)。先查标准正态分位系数 $k_题$:

$P_{题门槛}$80.0%90.0%95.0%(默认)97.5%99.0%
$k_题$0.84161.28161.64491.96002.3263

纳入门槛时间(即页面上的"有效答题时长"):

$$x_{门槛} \;=\; \mu_题 \;+\; k_题 \cdot \sigma_题$$

用默认 95% 时:$x_{门槛} = \mu_题 + 1.6449\,\sigma_题$。大于该值的单题视为超时,进入第 ⑤ 步替代。

($k_题$ 是从 $P_{题门槛}$ 反算的标准正态分位系数,$k_题 = \Phi^{-1}(P_{题门槛})$。配置变更时由系统计算一次存为常量,运行时只做一次乘法。)

⑤

对每道单题做超时判定与替代。记某用户在该车系问卷下的某一道作答时间为 $x_i$。直接对比时间与门槛即可(无需计算 $Z$、$P$):

$$x_i^{\,\ast} \;=\; \begin{cases}x_i, & x_i < x_{门槛}\\[4pt]\dfrac{\mu_题}{3}, & x_i \ge x_{门槛}\end{cases}$$

替代系数 $\tfrac{1}{3}$ 可配置(默认即 $\mu_题$ 除以 $3$)。$x_i^{\,\ast}$ 是该题进入步 ⑥ 累加的"有效时间"。

⑥

求和得到推定答题时长 $y$。对该 VIN 该问卷的全部单题:

$$y \;=\; \sum_{i=1}^{n_{当份题}} x_i^{\,\ast} \qquad(\text{秒})$$

页面展示时可同时给出分钟:$y\,(\text{分}) = y / 60$。

为什么是"替代"而不是"剔除" 若直接剔除超时题,不同问卷保留题数不同 → $y$ 不可比。改为以 $\tfrac{1}{3}\mu_题$ 替代后,每份问卷参与求和的题数恒等于该问卷应答题数,$y$ 在所有问卷之间天然可比,后续 §3.3 才有意义。

3.3第二步 · 问卷维度 · 异常判定

⑦

收集所有已回答问卷的推定时长。

$$\{y_1, y_2, y_3, \ldots, y_{n_卷}\}$$
⑧

计算 $\mu_卷$。

$$\mu_卷 \;=\; \frac{1}{n_卷}\sum_{j=1}^{n_卷} y_j$$
⑨

计算 $\sigma_卷$。

$$\sigma_卷 = \sqrt{\,\frac{1}{n_卷}\sum_{j=1}^{n_卷}(y_j - \mu_卷)^2\,}$$
⑩

计算异常下限,直接对比判定。取 $P_{卷门槛} = 5.0\%$(可配,1 位小数)。查标准正态分位系数 $k_卷$(负值,门槛在下侧):

$P_{卷门槛}$1.0%2.5%5.0%(默认)10.0%20.0%
$k_卷$−2.3263−1.9600−1.6449−1.2816−0.8416

异常下限(即页面上的"有效答卷时长"):

$$y_{门槛} \;=\; \mu_卷 + k_卷 \cdot \sigma_卷$$

用默认 5% 时:$y_{门槛} = \mu_卷 - 1.6449\,\sigma_卷$。判定规则直接比时间:

$$y_j \;\le\; y_{门槛} \;\Longrightarrow\; \text{异常·过快}$$

命中的问卷在人工审核表单整行高亮,作为不发积分的统计参考(最终是否发放仍以人工复核为准)。过慢的问卷不卡 —— 只设下限,不设上限。

3.4k 的运行时计算公式

$$k = \Phi^{-1}(P_{门槛})$$

PHP 实现(Acklam 近似,精度 ~$10^{-9}$;Excel NORM.S.INV、scipy norm.ppf 内部就是这个):

function inverseNormalCDF(float $p): float
{
    // Acklam approximation
    $a = [-39.69683028665376, 220.9460984245205, -275.9285104469687,
           138.3577518672690, -30.66479806614716, 2.506628277459239];
    $b = [-54.47609879822406, 161.5858368580409, -155.6989798598866,
           66.80131188771972, -13.28068155288572];
    $c = [-0.007784894002430293, -0.3223964580411365, -2.400758277161838,
          -2.549732539343734, 4.374664141464968, 2.938163982698783];
    $d = [0.007784695709041462, 0.3224671290700398,
          2.445134137142996, 3.754408661907416];

    $pLow  = 0.02425;
    $pHigh = 1 - $pLow;

    if ($p < $pLow) {                              // 下尾
        $q = sqrt(-2 * log($p));
        $num = ((((($c[0]*$q + $c[1])*$q + $c[2])*$q + $c[3])*$q + $c[4])*$q + $c[5]);
        $den = ((($d[0]*$q + $d[1])*$q + $d[2])*$q + $d[3])*$q + 1;
        return $num / $den;
    }
    if ($p <= $pHigh) {                            // 中间段(默认 5% / 95% 都在这)
        $q = $p - 0.5;
        $r = $q * $q;
        $num = ((((($a[0]*$r + $a[1])*$r + $a[2])*$r + $a[3])*$r + $a[4])*$r + $a[5]) * $q;
        $den = (((($b[0]*$r + $b[1])*$r + $b[2])*$r + $b[3])*$r + $b[4])*$r + 1;
        return $num / $den;
    }
    // 上尾(对称)
    $q = sqrt(-2 * log(1 - $p));
    $num = ((((($c[0]*$q + $c[1])*$q + $c[2])*$q + $c[3])*$q + $c[4])*$q + $c[5]);
    $den = ((($d[0]*$q + $d[1])*$q + $d[2])*$q + $d[3])*$q + 1;
    return -$num / $den;
}

调用:

$k_ti  = inverseNormalCDF(0.95);   // = 1.6448536...  (k题, 默认 P题门槛=95%)
$k_juan = inverseNormalCDF(0.05);  // = -1.6448536... (k卷, 默认 P卷门槛=5%)

建议在配置项保存时调用一次,把结果存到表里;运行时只是一次乘法 + 一次加法。

4关键设计原则

4.1 替代而非剔除

见 §3.2 末尾说明。每份问卷参与求和的题数恒定,$y$ 跨问卷可比。

4.2 多层兜底链

统计 $\mu$、$\sigma$ 时按以下顺序逐级回退,确保参照分布来自足够大的样本(每一级的样本量门槛固定为 2000):

层级使用的聚合表判定条件说明
① 问卷粒度
最精确		stat_questionnaire[Q]$n_卷^{(Q)} \ge 2000$该问卷自己的累计样本足够,直接使用
② 车系粒度stat_car_series[(M, T)]$n_卷^{(M,T)} \ge 2000$退到"该问卷所属车系 × 类型"层(类型相同保证样本同质)
③ 问卷类型粒度stat_questionnaire_type[T]$n_卷^{(T)} \ge 2000$退到"该问卷类型全量"(跨车系汇总)
④ 全品牌粒度
最兜底		stat_brand[B]无条件万能兜底,n 通常在百万级,$\mu$、$\sigma$ 极稳定

查找时从 ① 开始,$n_卷$ 不足就下沉到下一级,直到命中或落到 ④。题目级($\mu_题$、$\sigma_题$)用同一套查找路径,只是读 q_n / q_mu / q_m2 而非 s_n / s_mu / s_m2。

为什么逐级回退而不直接用品牌 车系/类型层离当前问卷的样本群最近(同车系、同类型的答题分布最接近);只有当这一层样本太小、统计不稳时,才退一步换更大的池子。这样既保留了精度,又规避了小样本误判。

4.3 向后运用 · 不回溯 · 提交即冻结

每当一份新问卷提交时,系统先用增量公式更新 $\mu$、$\sigma$(见 §5),再用门槛对比该问卷的 $y$ 与 $y_{门槛}$ 判定异常,结论冻结。已存在问卷的判定不再回溯重算。这样实现 $O(1)$ 入库,且发放结论可追溯。

4.4 单位以秒为底

$\mu$、$\sigma$、$y$、$x_{门槛}$、$y_{门槛}$ 在数据库与展示中统一以秒为单位,因为以分钟存 2 位小数会损失约 0.6 秒/档的精度;$y$ 在审核表单中可附加分钟列以便阅读。

4.5 单位无关性

$Z$ 是无量纲量。对任意正常数 $k$,以 $kx$ 为输入计算:

$$Z = \frac{kx - k\mu}{k\sigma} = \frac{x - \mu}{\sigma}$$

故 $Z$、$P$、异常判定与"用秒还是用分钟"结果完全相同,改单位只影响显示精度。

5增量补偿更新公式

每次有新数据无需全量重算 $\mu$、$\sigma$。维护三个滚动量即可:

$$\big(n,\ \mu,\ \sigma\big) \quad \text{(题目级、问卷级各一套,按车系/品牌存)}$$

下面公式给出的是精确值,与全量重算的结果完全一致(非近似)。

5.1 ① 单值补偿(来一个新 $x$)

设当前为 $(n,\mu,\sigma)$,新到一个 $x$:

$$n' = n + 1$$
$$\mu' = \mu + \frac{x - \mu}{n'}$$
$$\sigma'^{\,2} = \frac{n\,\sigma^{2} + (x-\mu)(x-\mu')}{n'}, \qquad \sigma' = \sqrt{\sigma'^{\,2}}$$

注意分子中是 $(x-\mu)$ 与 $(x-\mu')$ 两个不同的差,这是 Welford 的数值稳定形式。

5.2 ② 批量合并(来一批新数据)

已有聚合 $A=(n_A,\mu_A,\sigma_A)$,新一批先在批内独立算出 $B=(n_B,\mu_B,\sigma_B)$,合并:

$$n = n_A + n_B, \qquad \delta = \mu_B - \mu_A$$
$$\mu = \mu_A + \delta\cdot\frac{n_B}{n}$$
$$\sigma^{2} = \frac{\,n_A\,\sigma_A^{2} + n_B\,\sigma_B^{2} + \delta^{2}\cdot\dfrac{n_A\, n_B}{n}\,}{n}, \qquad \sigma = \sqrt{\sigma^2}$$

适用于"每天后台跑一次"或"一份问卷整批入库"等场景。

5.3 ③ Z、P 的处理(瞬时计算 + 冻结)

$Z$、$P$ 不是累积量,无需"增量更新"。对任意 $x_i$:

$$Z_i = \frac{x_i - \mu}{\sigma}, \qquad P_i = \Phi(Z_i)$$

新数据到达时的步骤:

  1. 先用 ① 或 ② 更新 $\mu$、$\sigma$。
  2. 对新提交的这一条算其 $Z$、$P$,并冻结落库。
  3. 已存在记录的旧 $Z$、$P$ 不重算(向后运用,见 §4.3)。

5.4 ④ 等价的简单写法(累加和)

若实现上不便存 $\sigma$,可改存两个累加和 $S_1 = \sum x$、$S_2 = \sum x^2$ 与 $n$:

$$\text{新}\,x:\;\; S_1\mathrel{+}= x,\;\; S_2\mathrel{+}= x^{2},\;\; n\mathrel{+}= 1$$
$$\mu = \frac{S_1}{n}, \qquad \sigma = \sqrt{\,\frac{S_2}{n} - \mu^{2}\,}$$
注意 当 $n$ 极大(数百万级),$\dfrac{S_2}{n} - \mu^2$ 是两个大数相减,可能出现严重精度损失(灾难性抵消)。建议海量数据场景使用 §5.1 的 Welford 写法,或显式维护 $M_2 = \sum(x_i - \mu)^2 = n\sigma^2$ 作为状态。

5.5 两个层级用同一套

层级$x$ 是什么状态
题目级单题作答时间(秒)$(n_题, \mu_题, \sigma_题)$,按车系存
问卷级问卷推定时长 $y$(秒)$(n_卷, \mu_卷, \sigma_卷)$,按车系存
